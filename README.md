## 維護 / Maintenance

- 本文：`content.mjs`（ja / en / zh-Hant，以 blocks 排列）。版面：`build.mjs`、`site.css`。圖片放大與目錄高亮：`gallery.js`。
- 修改後執行 `node build.mjs`，連同產生的 `index.html`、`en.html`、`zh.html` 一起提交。
- GitHub Pages 使用 main 分支根目錄。無追蹤器、無外部字型、無外部請求。
- 圖片：`assets/v150/`（主視覺、BOOTH 圖、工具畫面截圖）。截圖要用實際顏色（不要再做 gamma 轉換）。
- 本儲存庫只放公開說明與宣傳圖，不含產品程式、unitypackage 或 Avatar。
