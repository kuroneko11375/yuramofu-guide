YURAMOFU · USER GUIDE

A twitch of the ears,
a sway of the tail.

YuraMofu is a Unity Editor extension that builds idle and gesture-linked animations from your avatar's ear and tail bones. Check everything in the preview, then generate — it can add the layers to your FX Controller for you.

★New in v1.5.0

Gesture poses are now set on a pad instead of typed numbers, and gestures and idle motion fit together better.

Set poses on a pad

Drag forward/back and in/out for the ears, or up/down/left/right for the tail. A Turn dial turns the ears in or out. Poses move in the avatar's own directions, whatever the bone axes are.

Pause idle during gestures

While a gesture moves the ears or tail, that part's idle motion pauses so the pose reads clearly (on by default).

  • The Gesture Link layer is now additive. With no gesture it no longer stops the avatar's own tail sway, AFK motion or YuraMofu's idle motion.
  • Only Fist follows trigger pressure (GestureWeight). Other gestures show the full pose as soon as they are made.
  • Existing XYZ settings keep working, and raw XYZ entry is still under Direction.

After updating the tool, Generate or Update your Gesture Link to switch it to the new format.

01Getting started

Requirements: Unity 2022.3 LTS or later (Windows Unity Editor). Adding to FX, Gesture Link and the tail speed dial need the VRChat SDK3 Avatars; basic Animation Clips can be generated without it.

  1. Import and open

    Import the unitypackage and open 黒猫Dev → YuraMofu (ゆらもふ) → Open Window. Back up your project first.

  2. Pick the avatar and Auto Detect

    Put the scene avatar in the Avatar field and click Auto Detect. When ears, tail and FX show ✓ in the status bar, you are ready. Always check the result and fix bones in Bones & Details if needed.

  3. Choose a style and strength

    In the Idle Motion tab, choose a motion style and strength, then adjust the ears and tail.

  4. Preview

    Click Preview to see the motion in the Scene view. Nothing is written to assets or FX until you generate.

  5. Generate / Update

    Generate the first time; Update when changing existing output. A list of files and layers to be added or replaced is shown before anything is written.

02Idle Motion

Motion style and strength

  • Calm
  • Natural
  • Lively
  • Sleepy
  • Nervous
  • Silly
  • Whimsical

Strength is Soft, Normal or Strong. Choosing a style sets the ear and tail details to that style's values. Whimsical adds long stillness broken by single, mostly one-ear twitches, and an off-centre tail swaying at an uneven tempo.

Ears

Ear L/R
Auto, Sync or Async. In Sync, Single-Ear Share sets how often only one ear twitches.
Motion types
By default the ears only twitch. Add Ear Swivel (turns slowly outward and holds) and Ear Shake (flings the ear like shaking off water). Each has a checkbox and a Frequency (%).

Tail

Motion
Continuous or Intermittent.
Amplitude and base speed
1x is a 1.5-second cycle.
Suppleness (%)
Higher values calm the base and send the swing to the tip as a wave. 0 keeps the previous motion.
Swing Center and Tempo Variation
Swing around an off-centre point / vary the speed of each swing (Detailed Settings).
Tail speed dial
Turn on Generate Tail Speed Dial to change the idle tail speed with a dial in VRChat. Ear and Gesture Link speeds are unaffected.

Output mode

Bake Chain (Recommended)
Writes keys onto every bone in the chain. For ears and tails without PhysBone.
Physics-Friendly (Alternative)
Animates only the root and lets PhysBone carry the rest. Fewer keys and a softer result.

If the motion goes the wrong way, fix the axis with Axis Correction in Bones & Details. The defaults work for most avatars.

03Gesture Link (product version)

Set it up in this order: hand (GestureLeft / GestureRight) → F2-F8 → reaction type → ears and tail.

Reaction types

None
The gesture does not move the ears or tail.
Pose
Tilts the ears/tail toward the direction set on the pad. Fist follows trigger pressure from 0 to 100%; other gestures show the full pose right away.
Continuous Motion
Repeats the chosen style's ear or tail motion while the gesture is held.
Per Part
Assign None, Pose or Motion to the ears and tail separately.

Setting the direction on the pad

  • The further from the centre, the bigger the tilt. Left/right is as seen from the avatar.
  • Drag the pad and dial to adjust; double-click to return to the centre (0).
  • For the ears, Same mirrors the motion on both ears, Opposite makes the other ear do the reverse.
  • Open Direction to type XYZ directly. Typed XYZ is used until you move the pad again.
  • With Fist selected, Pose Preview (%) shows each pressure level.

Pause idle during gestures

Found under FX Settings (on by default). While a gesture moves a part, that part's idle motion pauses. Turn it off to layer gesture poses and motions on top of the idle motion. It is set up from the layers in the FX, whichever of idle or Gesture Link you generate first.

Copy To... copies the selected gesture's setup to another gesture or to all of them. The display name is not copied.

04Second ear/tail set

Turn on Enable second set at the top of each tab to switch between set 1 and set 2. Motion and speed are shared; only the axis correction is per set. Generate and Update output every enabled set.

Assign the second set's bones by hand (Auto Detect covers set 1). This is not a way to give the two sets different motion or speed.

05Generating, updating and the FX Controller

Preview
Shows the motion in the Unity Editor. Changes are not written to assets or FX until you Generate or Update.
Generate
Creates new Animation Clips and YuraMofu FX layers.
Update
Applies the current settings to existing output.
Add to FX automatically
Adds layers that play the generated motion to the avatar's FX Controller. Idle and Gesture Link layers are additive (Write Defaults ON, fixed) and add on top of the avatar's own motion.
Save location and update notice
Set under Idle Motion → FX & Save Location.

Unity's Undo cannot fully restore Animator Controller layers. Review the confirmation list shown before generating, and back up if needed.

Uninstall: 黒猫Dev → YuraMofu (ゆらもふ) → Uninstall from Active Avatar removes the layers YuraMofu added to the FX.

06FAQ

Does it work with PhysBone ears and tails?

Yes. Use Check compatibility in the status bar to check Is Animated and more. To leave the sway to PhysBone, use the Physics-Friendly output mode.

Can I use it with FaceEmo?

Generate FaceEmo first, then YuraMofu. Regenerating FaceEmo rebuilds the FX, so point YuraMofu at the new FX and regenerate it too.

What should I do after updating the tool?

Run Update after importing to apply fixes to existing output. If some output is missing, run Generate.

The motion goes the wrong way

For idle motion, use Axis Correction in Bones & Details. For gesture poses, set the direction on the pad.

Does it connect to the internet?

Once a day it checks for the latest version only. No project or avatar information is sent. You can turn it off under FX & Save Location, and it works offline.

Where are settings saved?

The window keeps the last set of settings per project. Clear Settings resets them (generated animations and layers are not deleted).

If something does not work, please contact me through BOOTH messages.
