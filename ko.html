★v1.5.3 새 기능

꼬리에 두 번째 이후의 본 체인을 추가할 수 있게 되었습니다. 트윈테일이나 앞치마 리본 등 꼬리가 아닌 흔들리는 부분도 함께 움직일 수 있습니다.

꼬리 본 추가

「본・세부 조정」의 「+ 체인 추가」로 두 번째 이후의 체인을 추가합니다. 강도・속도 등의 설정은 모든 체인이 공유합니다. 두 개 이상일 때는 「여러 체인의 움직임」에서 함께(같은 방향으로 흔들림) / 좌우 대칭(첫 번째 체인과 거울처럼) / 따로(각자의 타이밍)를 고릅니다.

귀 기울이기

가끔 귀를 세우고 잠시 멈췄다가 돌아옵니다. 무언가에 귀를 기울이는 듯한 움직임입니다. 방향 바꾸기・털기와 마찬가지로 앞의 체크와 「귀 기울이기 빈도 (%)」로 설정합니다. 켠 움직임의 합계는 100%까지이며, 나머지는 쫑긋하는 움직임이 됩니다.

  • 스타일을 고른 뒤 값을 직접 바꾸면 스타일 옆에 「조정됨」이 표시되고, 「스타일로 복원」으로 스타일 값으로 되돌릴 수 있습니다. 다른 스타일을 고를 때는 조정한 내용을 덮어써도 되는지 확인합니다.
  • 각 스타일 고유의 리듬이 항상 적용되며, 「활발함」은 그 리듬을 기준으로 빠르게 또는 느리게 합니다. 「안절부절」은 귀를 세우고 좌우 번갈아 바깥쪽을 보는 움직임이 되었습니다.
  • 아바타를 지정하면 본을 자동으로 감지합니다.
  • 생성・업데이트 전 확인 화면에도 FaceEmo의 WriteDefaults 주의 사항을 표시합니다.
  • 제거하기 전에 삭제할 항목 목록을 확인할 수 있습니다. 꼬리 속도 다이얼(FX 파라미터・메뉴 항목)과 제스처 중 대기 모션 정지용 Animation Clip도 함께 삭제합니다.

기존 출력에 반영하려면 툴을 업데이트한 뒤 「업데이트」를 실행해 주세요.

v1.5.2 새 기능

FaceEmo와 함께 쓸 때의 경고를 추가하고, 꼬리 움직임을 더 자연스럽게 했습니다.

  • FaceEmo가 「WriteDefaults オフ（表情優先）」로 적용되어 있으면 툴 화면에 경고가 표시됩니다. 귀・꼬리가 파묻히거나 뒤틀리는 원인이 됩니다. 경고가 나오면 FaceEmo에서 「WriteDefaults 統一（ギミック優先）」을 선택하고 「アバターに適用」을 다시 실행해 주세요.
  • FX 자체에 WriteDefaults가 꺼진 스테이트가 있어서 FaceEmo 설정만으로는 고쳐지지 않는 경우에도 안내를 표시합니다.
  • 꼬리 움직임이 「가끔」일 때, 흔들림이 끝날 때 뚝 멈추지 않고 점점 작아지며 자연스럽게 멈춥니다.
  • Expressions Menu・Parameters를 설정하지 않은(VRChat 기본 그대로인) 아바타에 속도 다이얼을 추가하면 VRCEmote와 표정용 파라미터가 사라지는 문제를 수정했습니다.

꼬리 움직임과 속도 다이얼 수정은 툴을 업데이트한 뒤 「업데이트」를 실행하면 기존 출력에 반영됩니다.

01시작하기

툴 화면은 오른쪽 위의 「KO」로 한국어로 바꿀 수 있습니다(v1.5.1 이후). 이 가이드의 스크린샷은 일본어 화면입니다.

동작 환경: Unity 2022.3 LTS 이상(Windows판 Unity Editor). FX 자동 추가, 제스처 연동, 꼬리 속도 다이얼에는 VRChat SDK3 Avatars가 필요합니다. SDK가 없어도 기본 Animation Clip은 생성할 수 있습니다.

  1. 임포트해서 열기

    unitypackage를 프로젝트에 임포트하고 메뉴의 黒猫Dev → YuraMofu (ゆらもふ) → Open Window를 엽니다. 작업 전에 프로젝트를 백업하는 것을 권장합니다.

  2. 아바타를 지정하고 「자동 감지」

    Scene에 있는 아바타를 「아바타」 칸에 넣고 「자동 감지」를 누릅니다. 상태 표시줄의 귀・꼬리・FX가 ✓가 되면 준비 완료입니다. 검출 결과는 꼭 확인하고, 다르면 「본・세부 조정」에서 다시 지정하세요.

  3. 스타일과 강도 고르기

    「대기 모션」 탭에서 모션 스타일과 강도를 고르고, 귀와 꼬리를 각각 조정합니다.

  4. 프리뷰로 확인

    「미리보기」로 Scene에서 움직임을 확인합니다. 프리뷰 중에 바꾼 내용은 생성하기 전까지 에셋이나 FX에 기록되지 않습니다.

  5. 생성 / 업데이트

    처음에는 「생성」, 이미 생성한 움직임을 바꿀 때는 「업데이트」를 누릅니다. 내보낼 파일과 추가・교체될 레이어 목록을 확인한 뒤 실행됩니다.

02대기 모션

모션 스타일과 강도

  • 얌전하게
  • 자연스럽게
  • 활발하게
  • 졸린 듯
  • 안절부절
  • 장난스럽게
  • 변덕스럽게

강도는 「약하게 / 보통 / 강하게」 중에서 고릅니다. 스타일을 고르면 귀・꼬리의 세부 설정이 그 스타일의 값으로 바뀝니다. 값을 직접 바꾸면 「조정됨」이 표시되며, 「스타일로 복원」으로 되돌릴 수 있습니다. 변덕스럽게은 오래 가만히 있다가 가끔 한쪽 귀만 짧게 쫑긋하고, 꼬리는 한쪽으로 치우친 채 완급을 주며 흔들리는 스타일입니다.

귀

귀 좌우
자동 / 동기 / 비동기. 동기일 때는 「한쪽 귀만 움직이는 비율」로 한쪽 귀만 쫑긋할 확률을 정할 수 있습니다.
움직임 종류
기본은 쫑긋하는 움직임뿐이지만, 「귀 방향 바꾸기」(천천히 바깥쪽으로 돌아가서 멈춤), 「귀 털기」(물기를 털듯이 흔듦), 「귀 기울이기」(귀를 세우고 잠시 멈춤)를 추가할 수 있습니다. 앞의 체크로 ON/OFF, 「빈도 (%)」로 비율을 정합니다. 켠 움직임의 합계는 100%까지이며, 나머지는 쫑긋하는 움직임이 됩니다.

꼬리

본
「+ 체인 추가」로 두 번째 이후의 본 체인(트윈테일・리본 등)을 추가할 수 있습니다. 「여러 체인의 움직임」에서 함께 / 좌우 대칭 / 따로를 고릅니다.
움직임 모드
연속 진자 / 간헐 흔들기.
진폭・기본 속도
1배는 한 주기 1.5초입니다.
유연함 (%)
올릴수록 뿌리 쪽은 차분해지고, 흔들림이 물결처럼 끝으로 전해집니다. 0이면 기존과 같습니다.
흔들림 중심・흔들림 완급
좌우 한쪽으로 치우쳐 흔들기 / 한 번 흔들 때마다 속도에 변화를 주기(세부 조정).
꼬리 속도 다이얼
「꼬리 속도 다이얼 생성」을 ON으로 하면 VRChat 안에서 다이얼로 대기 중인 꼬리 속도를 바꿀 수 있습니다. 0%로 하면 꼬리가 원래 위치로 돌아가서 멈춥니다. 귀와 제스처 연동의 속도는 바뀌지 않습니다.

생성 방식

본마다 (권장)
체인 전체의 본에 키를 기록합니다. PhysBone이 없는 귀・꼬리용입니다.
물리에 맡기기 (대체)
뿌리만 움직이고 나머지 흔들림은 PhysBone에 맡깁니다. 키가 적고 부드러운 움직임이 됩니다.

움직이는 방향이 이상할 때는 「본・세부 조정」의 「방향 보정」으로 축을 고치세요. 보통은 기본 설정 그대로도 문제없습니다.

03제스처 연동(풀 버전)

손(GestureLeft / GestureRight) → F2~F8 → 리액션 타입 → 귀・꼬리 순서로 설정합니다.

리액션 타입

없음
그 제스처에서는 귀・꼬리를 움직이지 않습니다.
포즈
패드로 정한 방향으로 귀・꼬리를 기울입니다. Fist는 트리거를 누르는 정도에 따라 0~100%로 변하고, 다른 제스처는 누르는 순간 100%가 됩니다.
연속 모션
그 제스처를 하는 동안 고른 스타일의 귀・꼬리 움직임을 반복합니다.
부위별
귀와 꼬리에 각각 「없음 / 포즈 / 모션」을 지정합니다.

패드로 방향 정하기

  • 패드 중심에서 멀어질수록 크게 기울어집니다. 좌우는 아바타 본인이 본 방향입니다.
  • 패드와 다이얼은 드래그로 조정하고, 더블클릭하면 중앙(0)으로 돌아갑니다.
  • 귀의 「같은 방향」은 양쪽 귀가 좌우 대칭으로 같은 움직임, 「반대 방향」은 다른 쪽 귀가 반대로 움직입니다. 「왼쪽 귀만」「오른쪽 귀만」은 한쪽 귀만 움직이고, 「좌우 따로」는 귀마다 패드로 방향을 정합니다.
  • XYZ로 직접 입력하고 싶을 때는 「방향 조정」을 엽니다. XYZ를 입력하면 패드를 다시 움직이기 전까지 XYZ 값이 사용됩니다.
  • Fist를 선택 중일 때는 「포즈 미리보기 (%)」로 누르는 정도별 모습을 확인할 수 있습니다.

제스처 중에는 대기 모션 정지

「FX 설정」에 있는 설정입니다(기본값 ON). 제스처로 움직이는 부위의 대기 모션을 그동안만 멈춥니다. OFF로 하면 제스처의 포즈・모션이 대기 모션 위에 겹쳐집니다. 대기와 제스처 연동 중 어느 쪽을 먼저 생성해도 FX 안의 레이어를 보고 자동으로 설정됩니다.

「다른 제스처로 복사」로 선택 중인 제스처의 설정을 다른 제스처(또는 모든 제스처)에 복사할 수 있습니다. 표시 이름은 복사되지 않습니다.

04두 번째 귀・꼬리

각 탭 위쪽의 「두 번째 세트 사용」을 ON으로 하면 첫 번째/두 번째 세트를 전환하며 편집할 수 있습니다. 움직임과 속도는 공통이고, 축 보정만 세트별로 조정합니다. 생성・업데이트 시에는 활성화된 세트를 모두 출력합니다.

두 번째 세트의 본은 직접 지정해 주세요(「자동 감지」는 첫 번째 세트만 대상입니다). 두 세트를 각각 다른 움직임・속도로 움직이는 기능은 아닙니다.

05생성・업데이트와 FX Controller

미리보기
Unity Editor에서 움직임을 확인합니다. 프리뷰 중에 바꾼 내용은 생성・업데이트하기 전까지 에셋이나 FX에 반영되지 않습니다.
생성
Animation Clip과 유라모후용 FX 레이어를 새로 만듭니다.
업데이트
이미 생성한 데이터에 현재 설정을 반영합니다.
FX 자동 추가
아바타의 FX Controller에 생성한 움직임을 재생하는 레이어를 추가합니다. 대기・제스처 연동 레이어는 Additive(Write Defaults ON 고정)이며, 아바타 본래의 움직임 위에 더해집니다.
저장 위치・업데이트 알림
「대기 모션」 → 「FX・저장 위치」에서 설정합니다.

Unity의 Undo로는 Animator Controller의 레이어를 완전히 되돌릴 수 없습니다. 생성 전에 표시되는 확인 목록을 보고 실행하고, 필요하면 백업해 두세요.

제거: 黒猫Dev → YuraMofu (ゆらもふ) → Uninstall from Active Avatar를 실행하면 삭제할 항목 목록이 표시되고, 확인 후 유라모후가 추가한 레이어・파라미터・메뉴 항목을 삭제합니다.

06자주 묻는 질문

PhysBone이 들어간 귀・꼬리에도 쓸 수 있나요?

쓸 수 있습니다. 상태 표시줄의 「호환성 확인」로 PhysBone의 Is Animated 등을 확인할 수 있습니다. 흔들림을 PhysBone에 맡기고 싶을 때는 생성 방식을 「물리에 맡기기」로 해 주세요.

FaceEmo와 함께 쓸 수 있나요?

FaceEmo → 유라모후 순서로 생성해 주세요. FaceEmo를 다시 생성하면 FX가 새로 만들어지므로, 새 FX를 지정해서 유라모후도 다시 생성해 주세요.

툴을 업데이트한 뒤에는 무엇을 하면 되나요?

임포트 후 「업데이트」를 실행하면 기존 출력에 수정 사항이 반영됩니다. 필요한 출력이 없으면 「생성」를 실행해 주세요.

움직이는 방향이 이상해요

대기 모션은 「본・세부 조정」의 「방향 보정」으로, 제스처 연동 포즈는 패드로 방향을 고쳐 주세요.

Play Mode나 VRChat에서 귀가 머리에 파묻히거나, 꼬리가 비틀리거나, 움직임이 굳어요

FX 안에서 Write Defaults ON / OFF가 섞여 있으면 생깁니다. FaceEmo나 페이스 트래킹의 표정 비활성화 기능(Triturbo 확장 등)이 원인인 경우가 많으며, 유라모후의 대기 모션(Write Defaults ON 필요)의 자세가 무너집니다. 본이나 방향 설정을 바꿔도 고쳐지지 않습니다. 원인으로 보이는 기믹을 잠시 빼고 Play Mode에서 확인한 뒤, FX의 Write Defaults를 통일해 주세요. FaceEmo를 쓰는 경우에는 통일한 다음 FaceEmo → 유라모후 순서로 생성해 주세요. 그래도 고쳐지지 않으면 黒猫Dev → YuraMofu (ゆらもふ) → Copy Diagnostics 결과를 첨부해 BOOTH 메시지로 연락해 주세요.

인터넷에 연결하나요?

하루 한 번 최신 버전만 확인합니다. 프로젝트나 아바타 정보는 보내지 않습니다. 「FX・저장 위치」에서 끌 수 있으며, 오프라인에서도 사용할 수 있습니다.

설정은 어디에 저장되나요?

창의 설정은 프로젝트마다 마지막 한 세트를 저장합니다. 「설정 초기화」로 초기값으로 되돌릴 수 있습니다(생성한 애니메이션과 레이어는 삭제하지 않습니다).

잘 되지 않을 때는 BOOTH 메시지로 문의해 주세요.
