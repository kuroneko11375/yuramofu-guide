YURAMOFU · USER GUIDE

耳がぴくっと、
尻尾がゆらり。

ゆらもふは、耳・尻尾のボーンから待機モーションやジェスチャー連動のアニメーションを作る Unity Editor 拡張です。プレビューで確かめてから生成し、FX Controller へのレイヤー追加まで自動で行えます。

★v1.5.2 の新機能

FaceEmo と併用したときの注意表示と、尻尾の動きの改善を追加しました。

  • FaceEmo を「WriteDefaults オフ（表情優先）」で適用していると、ツール画面に警告が出るようになりました。耳・尻尾が埋まったり、ねじれたりする原因になります。警告が出たら、FaceEmo で「WriteDefaults 統一（ギミック優先）」を選び、「アバターに適用」をやり直してください。
  • FX に WriteDefaults オフのステートがあり、FaceEmo の設定だけでは直らない場合も、その旨を表示します。
  • 尻尾の動きが「たまに」のとき、揺れの終わりでぴたっと止まらず、だんだん小さくなって自然に収まるようになりました。
  • Expressions Menu・Parameters を設定していない（VRChat 標準のままの）アバターに速度ダイヤルを追加すると、VRCEmote や表情用のパラメータが消えてしまう問題を修正しました。

尻尾の動きと速度ダイヤルの修正は、ツールを更新したあと「更新」を実行すると既存の出力に反映されます。

v1.5.1 の新機能

手勢連動のポーズで、左右の耳を別々に動かせるようになりました。

左右の耳を別々に

「耳の左右動作」で「左右別々」を選ぶと、耳ごとにパッドと「向き」ダイヤルが出ます。アバターを正面から見た並び（Scene ビューと同じ向き）で、各パッドの上には耳のボーン名が出ます。パッドを外側へ動かすと耳が開きます。

  • 「左耳だけ」「右耳だけ」を追加。片方の耳だけを動かし、もう片方は元の位置のままにします。
  • 尻尾速度のダイヤルを 0% にすると、途中の角度で固まらず、尻尾が元の位置に戻って止まるようになりました。
  • ツール画面が韓国語（한국어）に対応。画面右上の「KO」で切り替えます。

速度ダイヤルの変更は、ツールを更新したあと「更新」を実行すると既存の出力に反映されます。

01はじめに

動作環境：Unity 2022.3 LTS 以降（Windows 版 Unity Editor）。FX への自動追加・手勢連動・尻尾速度のダイヤルには VRChat SDK3 Avatars が必要です。SDK がなくても基本の Animation Clip は生成できます。

  1. インポートして開く

    unitypackage をプロジェクトへインポートし、メニューの 黒猫Dev → YuraMofu (ゆらもふ) → Open Window を開きます。作業前にプロジェクトのバックアップをおすすめします。

  2. アバターを指定して「自動検出」

    Scene 上のアバターを「アバター」欄に入れて「自動検出」。状態欄の耳・尻尾・FX が ✓ になれば準備完了です。検出結果は必ず確認し、違っていれば「ボーン・詳細調整」で指定し直します。

  3. スタイルと強さを選ぶ

    「挙動・揺れ」タブでモーションスタイルと強さを選び、耳・尻尾それぞれを調整します。

  4. プレビューで確認

    「プレビュー」で Scene 上の動きを確認します。プレビュー中の変更は、生成するまでアセットや FX に書き込まれません。

  5. 生成 / 更新

    初回は「生成」、生成済みの動きを変えるときは「更新」。書き出すファイルと追加・置き換えになるレイヤーの一覧を確認してから実行されます。

02挙動・揺れ（待機モーション）

モーションスタイルと強さ

  • おとなしい
  • 自然
  • 元気
  • 眠そう
  • そわそわ
  • おちゃめ
  • きまぐれ

強さは「弱め／ふつう／強め」。スタイルを選ぶと、耳・尻尾の細かな設定がそのスタイルの値になります。きまぐれは、長い静止の合間に片耳だけの短いぴくっと、中心が片側に寄った緩急のある尻尾の揺れが入るスタイルです。

耳

耳の左右
おまかせ／同期／非同期。同期のときは「片耳だけ動く割合」で、片方だけぴくっと動く確率を設定できます。
動きの種類
通常はぴくっと動くだけですが、「耳の向き変え」（ゆっくり外へ向けて止まる）と「耳をぶるっと振る」（水を払うように振る）を追加できます。行頭のチェックで ON/OFF、「頻度 (%)」で割合を決めます。

尻尾

動き
連続振り子／間欠振り。
振幅・基本速度
1 倍は 1 周期 1.5 秒です。
しなやかさ (%)
上げるほど根元が落ち着き、揺れが波のように先へ伝わります。0 で従来どおり。
振れの中心・揺れの緩急
左右どちらかに寄せて揺らす／1 回ごとの速さにばらつきを付ける（詳細調整）。
尻尾速度のダイヤル
「尻尾速度のダイヤルを生成」を ON にすると、VRChat 内のダイヤルで待機中の尻尾の速さを変えられます。0% にすると尻尾は元の位置に戻って止まります。耳や手勢連動の速さは変わりません。

生成方式

ボーンごと（推奨）
チェーン全体のボーンにキーを書き込みます。PhysBone が入っていない耳・尻尾向け。
物理まかせ（代替）
根元だけを動かし、残りの揺れは PhysBone に任せます。キーが少なく柔らかい動きになります。

動く方向がおかしいときは「ボーン・詳細調整」の方向補正で軸を直します。通常は初期設定のままで問題ありません。

03手勢連動（Gesture Link・製品版）

手（GestureLeft / GestureRight）→ F2～F8 → リアクションタイプ → 耳・尻尾の順に設定します。

リアクションタイプ

なし
その手勢では耳・尻尾を動かしません。
ポーズ
パッドで決めた向きへ耳・尻尾を倒します。Fist はトリガーの押し具合で 0～100% に変化し、他の手勢は押した瞬間に 100% になります。
連続モーション
その手勢の間、選んだスタイルの耳・尻尾の動きを繰り返します。
部位別
耳と尻尾それぞれに「なし／ポーズ／モーション」を割り当てます。

パッドで向きを決める

  • パッドの中心から離すほど大きく倒れます。左右はアバター本人から見た向きです。
  • パッドやダイヤルはドラッグで調整、ダブルクリックで中央（0）に戻ります。
  • 耳の「同方向」は両耳が左右対称に同じ動き、「反対方向」はもう片方の耳が逆の動きになります。「左耳だけ」「右耳だけ」は片方の耳だけが動き、「左右別々」は耳ごとにパッドで向きを決めます。
  • XYZ で直接入力したいときは「方向の調整」を開きます。XYZ を入力すると、パッドを動かすまでは XYZ の値が使われます。
  • Fist を選択中は「ポーズのプレビュー (%)」で押し具合ごとの見え方を確認できます。

ジェスチャー中は待機を止める

「FX 設定」にある設定です（初期値 ON）。ジェスチャーで動かしている部位の待機モーションを、その間だけ止めます。OFF にすると、ジェスチャーのポーズ・モーションが待機モーションの上に重なります。待機・手勢連動のどちらを先に生成しても、FX 内のレイヤーから自動で設定されます。

「他の手勢へコピー」で、選択中の手勢の設定を別の手勢（またはすべての手勢）へコピーできます。表示名はコピーされません。

042組目の耳・尻尾

各タブ上部の「2組目を使用」を ON にすると、1組目／2組目を切り替えて編集できます。動き・速度は共通で、軸補正だけを組ごとに調整します。生成・更新では有効な両組を出力します。

2組目のボーンは手動で指定してください（自動検出は1組目が対象）。2組をそれぞれ違う動き・速度で動かす機能ではありません。

05生成・更新と FX Controller

プレビュー
Unity Editor 上で動きを確認します。プレビュー中の変更は、生成・更新するまでアセットや FX に反映されません。
生成
Animation Clip と、ゆらもふ用の FX レイヤーを新しく作ります。
更新
生成済みのデータへ今の設定を反映します。
FX に自動追加
アバターの FX Controller に、生成した動きを再生するレイヤーを追加します。待機・手勢連動のレイヤーは Additive（Write Defaults ON 固定）で、アバター本来の揺れの上に加算されます。
保存先・更新通知
「挙動・揺れ」→「FX・保存先」で設定します。

Unity の Undo では Animator Controller のレイヤーを完全には戻せません。生成前に表示される確認一覧を見てから実行し、必要ならバックアップを取ってください。

アンインストール：黒猫Dev → YuraMofu (ゆらもふ) → Uninstall from Active Avatar で、ゆらもふが追加したレイヤーを FX から削除できます。

06よくある質問

PhysBone が入った耳・尻尾でも使えますか？

使えます。状態欄の「互換性を確認」で PhysBone の Is Animated などを確認できます。揺れを PhysBone に任せたいときは生成方式を「物理まかせ」にしてください。

FaceEmo と一緒に使えますか？

FaceEmo → ゆらもふの順で生成してください。FaceEmo を再生成すると FX が作り直されるので、新しい FX を指定してゆらもふも再生成してください。

ツールを更新したあと、何をすればいいですか？

インポート後に「更新」を実行すると、既存の出力に修正が反映されます。必要な出力がない場合は「生成」を実行してください。

動く方向がおかしいです

待機モーションは「ボーン・詳細調整」の方向補正、手勢連動のポーズはパッドで向きを直してください。

Play Mode や VRChat で、耳が頭に埋まる・尻尾がねじれる・動きが固まります

FX の中で Write Defaults の ON / OFF が混ざっていると起こります。FaceEmo やフェイストラッキングの表情無効化機能（Triturbo の拡張など）が原因になることが多く、ゆらもふの待機モーション（Write Defaults ON が必要）の姿勢が崩れます。ボーンや方向の設定を変えても直りません。原因になっていそうなギミックを一時的に外して Play Mode で確認し、FX の Write Defaults を統一してください。FaceEmo を使う場合は、統一したうえで FaceEmo → ゆらもふの順で生成してください。直らない場合は 黒猫Dev → YuraMofu (ゆらもふ) → Copy Diagnostics の結果を添えて BOOTH のメッセージでご連絡ください。

インターネットに接続しますか？

1 日 1 回、最新バージョンの確認だけを行います。プロジェクトやアバターの情報は送信しません。「FX・保存先」から無効にでき、オフラインでも使えます。

設定はどこに保存されますか？

ウィンドウの設定は、プロジェクトごとに最後の 1 組を保存します。「設定をクリア」で初期値に戻せます（生成済みのアニメーションやレイヤーは削除しません）。

うまくいかないときは、BOOTH のメッセージからお問い合わせください。
